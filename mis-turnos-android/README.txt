Mis turnos - proyecto Android
1. Abre esta carpeta con Android Studio (File > Open).
2. Espera a que termine de sincronizar Gradle.
3. Build > Build App Bundle(s) / APK(s) > Build APK(s).
4. La APK queda en app/build/outputs/apk/debug/app-debug.apk. Pásala al móvil e instálala.
Tus datos (cambios, vacaciones) se guardan en el propio móvil.
